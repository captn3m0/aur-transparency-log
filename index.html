Trusted publish timestamps for AUR commits, so AUR helpers can enforce dependency cooldowns (among other things).

This observer records when a commit was first seen on aur.archlinux.org and signs it. The time comes from Sigstore's timestamp authority - you can trust it without trusting this website.

API

Base URL https://aur-tl.captnemo.in. All endpoints are GET with open CORS.

EndpointExample
Newest commit at or before a cutoff/v1/pkg/python-transformers?before=4102444800

History, newest first/v1/pkg/python-transformers/history

Signed bundle/b/1795649492-6b25f276.sigstore.json
Signing key (JWK)/v1/keys
Signing key (PEM)/v1/keys.pem
JWKS/jwks.json
OIDC discovery/.well-known/openid-configuration
Health (cron age and last error)/healthz

/v1/pkg returns a status:

  • ok
  • too_new (the newest commit is newer than the cutoff; fail the cooldown or roll back via /history)
  • not_observed. A bad before returns 400 with the rounded value in suggest.
